# Data inputs and provenance

Every dataset is labelled with one of the project's three labels.
**Never mix them in one table, chart or alert without showing the label.**

| Folder | Label | Source | Notes |
|---|---|---|---|
| `task1/` | **SIMULATED DATA** | Generated by Task 1 (`generate_simulated_vitals.py`, seed 575) | 4 demo crew (DEMO-01..04), 14 days, 19 indicators. Not measured from a person, not NASA data. |
| `osd575/` | **REAL NASA RESEARCH DATA** | NASA OSDR study OSD-575 (SpaceX Inspiration4 serum cardiovascular panel, Eve Technologies HDCVD9) | 4 participants (C001-C004), 7 blood draws each = 28 rows. Periodic lab data only: no heart rate, SpO2, blood pressure, temperature or sleep. |

## Task 1 files used by the code
- `simulated_vitals_long.zip` : the long-format measurements (the loader reads the zip directly)
- `metric_table.csv` : per-indicator sourced ranges and "impossible if" rules
- `reference_ranges.csv` : published bands (NEWS2, AHA, AASM). Hospital/general-population bands, **not validated for astronauts**
- `daily_schedule.csv` : exact sleep and exercise windows
- `planted_events.csv` : answer key (20 rows) used only for testing/evaluation
- `README_from_task1.md` : Task 1's own documentation (version 3)

## OSD-575 notes verified from the files
- `haptoglobin` = 17,907,000 ng/mL appears 7 times (probable assay ceiling, treat as censored).
- L-44 is low for haptoglobin, PF4 and CRP in all four participants (possible batch/handling effect).
- Each `_percent` column equals 100 x concentration / mean of the 12 pooled pre-flight samples.
  This is an inference from the numbers, not documented by the metadata.
